  血缘页断链，而对账仍把该批算作血统齐全（假绿）。

## 拍板：甲路径（同事务写边，否则整笔回退拒收）

采样批落库瞬间，血缘父子边（`edge_type=parent_child`，状态 `正式`）在**同一事务**写入；
边写不入则整笔回退、入库拒收。续采批必须携带或可解析出父批：

1. 请求显式给 `parent_sample_id` → 校验父批存在且同排放口，否则拒收；
2. 未显式给 → 自动衔接同排放口最新批为父批；
3. 排放口首批（根批）无父，合法无边；
4. 除根批外，入库必须带出血缘父子边，否则拒收（污水域核销庚）。

## 明确禁止

- 禁止折中双写：不走乙路径影子连边草稿 + 升正，也不甲乙混用。
- 禁止只调血缘页连线视觉充数；禁止无复现改连线视觉。
- 禁止单点边插入救齐三红；三红分服务救绿（采样服务 / 血缘服务 / 锁与争用）。
- 影子边（`status=影子`）永不升正即永不得被血缘页当正式链、不得计入对账血统齐全。

## 争用口径

两路会话在同一父批下抢续采，须抢批锁 `sample:{父批id}`；后到争用只记痕
（`contention_log` 留 `争用失败`），败方零边零批。

## 五页账实同态

血缘页、采样页、对账页、封批页、排放口页五处须账实同态：

- 血缘页只展正式链，且可见父子边编号；
- 采样页展示批血统状态，续采入口依赖边表；
- 对账页血统齐全计数扣无边批；
- 封批页拒绝对无边批升代；
- 排放口页续采入口（采样页续采表单，按排放口解析父批）依赖边表存在。

## 偏离处理

偏离本说明的写边一律记 `写边偏航拒写`：凡绕过同事务写边、试图补单点边、
或把影子边当正式链的写入，拒绝落库并留审计痕。
